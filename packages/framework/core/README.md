# @openwhaleorg/core

The OpenWhale trading-automation framework: the runtime, the plugin contract (`definePlugin`, `@OwStrategy` / `@OwMonitor` / `@OwExecutor` / `@OwAccount`), the venue × kind adapter matrix, accounts, monitors, executors and strategies.

Plugins and strategy packages depend on this package; the gateway and dashboard live in the [OpenWhale](https://github.com/OpenWhale-Org/OpenWhale) repository, which also carries the plugin-development guide (`skills/openwhale-dev`).
