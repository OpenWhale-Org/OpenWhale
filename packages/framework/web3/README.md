# @openwhaleorg/web3

Chain access for OpenWhale: the `web3/chain` kind (an EVM read/sign session), the `EVM Wallet` account view, and the `web3/evm` wallet-key and `web3/rpc` endpoint credential types. On-chain venue plugins (Pendle, …) depend on it for the wallet key family and never ship a chain client of their own.

Part of [OpenWhale](https://github.com/OpenWhale-Org/OpenWhale).
